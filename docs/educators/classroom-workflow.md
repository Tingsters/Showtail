# Classroom workflow

Students connect their AI tools once, work normally, review a private report, and create
a sanitized submission with `showtail submit`. No assignment template, repository marker,
Git hooks, or committed working trail is required.

Ask students to hand in the generated export folder. Open `report.html` and run
`showtail verify-submission <folder>` to check its integrity. Assess their prompts,
decisions, changes, and explanation together. Showtail is a process record, not an AI
detector, grading system, or proof of authorship.
